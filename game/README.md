# 《人狼村》多人連線遊戲

依 [`GAME_RULES_FINAL_ZH_TW.md`](../GAME_RULES_FINAL_ZH_TW.md) 完整實作的 PC 多人連線版：
權威伺服器 + 瀏覽器客戶端，6–15 個角色槽位，真人與公開標示的 AI 玩家混合成局，支援斷線 AI 代管與重連。

---

## 快速開始（房主）

1. 安裝 [Node.js](https://nodejs.org/)（v18 以上）。
2. 雙擊 **`start_game.bat`**（或在此資料夾執行 `npm install` 後 `npm start`）。
3. 瀏覽器自動開啟 `http://localhost:8787`，輸入名字建立房間。
4. 大廳會顯示你的**區網網址**（例如 `http://192.168.x.x:8787`）——朋友在同一個 Wi-Fi／區網用瀏覽器開這個網址，輸入名字與 4 位房間代碼即可加入。
5. 人數不足的槽位由 AI 補足（身分公開標示），房主按「開始遊戲」。

### 跨網路連線（朋友不在同一個網路）

任選一種通道工具，把 8787 端口分享出去：

- **Tailscale**（推薦）：雙方安裝並登入同一網路，朋友連 `http://<你的Tailscale IP>:8787`。
- **ngrok**：`ngrok http 8787`，把產生的網址給朋友。
- 或在路由器設定 8787 端口轉發。

### 斷線與重連

- 遊戲中斷線的玩家由 AI 暫時代管（規則 3.3），座位標示「AI代管」。
- 用**同一個瀏覽器**重新開啟遊戲網址即可自動回到座位；也可在首頁按「回到上一場」。

## 已實作內容

- **完整正式規則書**：準備日、黎明流程、食物與逐次飢荒、第二日警長競選（1.5 票、發言順序、警徽移交／撕毀）、建設提案與表決（大燈／柵欄／烽火台）、一般放逐（匿名投票、公開去向、平票 PK）、狼人自爆、騎士決鬥中斷。
- **夜間十五步結算**（內部附錄 §4）：地點牌×3＋夜行令、花蝴蝶、守衛巡邏（連守限制）、狼隊 30 秒密談、15 秒長按工作、狼刀／自殺／偷懶／三種地圖破壞、烽火台神蹟、兩個攻擊批次與女巫雙救援窗口、預言家／禁票長老、潛行者暗殺、暗夜術士挽救、暗戀猜測、九尾狐尾數連鎖。
- **全部 14 個職業**與 7 個內建 12 人板子＋依人數自動配置。
- **資訊安全**：每個玩家只收到規則允許的資訊（夜死黎明前保密、看不到自己的匿名外觀、按鈕禁用狀態即情報、偷懶與工作對外完全一致）。
- **聊天頻道**：白天會議（輪流／自由發言）、夜間地點匿名頻道（顯示匿名外觀名）、狼隊頻道、亡者頻道；結構化聲明（聲稱職業／報查驗／指控／力保）供 AI 理解真人發言。
- **AI 玩家**：啟發式決策（目的地策略、懷疑度投票、各職業夜間能力、預言家跳身分報查驗），占位公開標示。
- **公開紀錄**：死亡、投票去向、資源變動、大燈／瞭望塔地點人數報告（依房主資訊模式）。
- **遊戲內圖鑑**：角色指南（傳說文案／能力／機制 QA）、地點與背景，文字全數取自正式文件。

## 本版未包含（未來工作）

- **即時語音與變聲**：目前以文字聊天承載（夜間地點頻道天然匿名）。語音需 WebRTC + DSP 變聲管線，介面已按頻道模型設計，可後接。
- **LM 語言模型 AI**：內部附錄 §10 列為獨立規格；現為啟發式 AI。
- **自訂職業配置編輯器**：附錄 §10 列為未展開；現提供內建板子＋自動配置。
- **夜間時長填充**：祕密階段以「夜色深沉」遮蔽內容，但夜晚總時長仍可能洩漏微量資訊。
- 伺服器重啟後進行中的對局不保留（大廳與規則無損）。

規則文件未明處的實作裁定全部記錄在 [`DEV_NOTES.md`](./DEV_NOTES.md)。

## 架構

```
game/
├─ core/          規則引擎（伺服器執行；純 JS、可測試、可重現）
│  ├─ data*.js      職業／地點／板子／文案／圖鑑（機制與文案分層）
│  ├─ model.js      狀態模型與判定輔助（保護矩陣、勝負、投票權…）
│  ├─ engine.js     階段機底盤（awaiting＋逾時預設值＋中斷）
│  ├─ phases_day.js 白天流程　phases_night.js 夜間十五步
│  ├─ deaths.js     死亡佇列（暗戀猜測→死亡→九尾狐→勝負→遺言→死亡能力→警徽）
│  └─ views.js      資訊過濾層：每座位個人化視圖（唯一的資訊出口）
├─ ai/ai.js       啟發式 AI（也負責斷線代管）
├─ server/        HTTP 靜態檔＋WebSocket 房間／重連／視圖推送
├─ client/        瀏覽器客戶端（零框架；晝夜雙主題）
├─ tests/         規則單元測試＋全 AI 整局＋真實 WebSocket 整合測試
└─ tools/         圖標打包
```

- 所有規則判定都在伺服器；客戶端只渲染個人化視圖與送出輸入。
- 亂數可播種、時間由外部推進，整局可重現（測試即基於此）。
- `WV_SPEED` 環境變數可整體縮放時間（測試用，如 `WV_SPEED=0.35`）。
