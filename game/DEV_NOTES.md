# 開發決策紀錄

規則文件未明確規定之處的實作裁定。每一條都可以被推翻——改動時請同步修改對應測試。

## 流程裁定

| 情境 | 規則文件 | 實作裁定 |
|---|---|---|
| 警長選舉 PK 後再度平票 | 未規定 | 本局沒有警長 |
| 「系統不允許所有人參選」的執行方式 | 未規定機制 | 報名結算時若候選人＝全部存活者，取消最大號碼者的參選並公告 |
| 候選人退選時機 | 「發言後可以退選」 | 競選發言階段內隨時可退選；投票開始後不可 |
| 第一天會議形式 | 未指定 | 一律自由討論（全員可提前結束），第二天起依房主設定 |
| 預言家查驗逾時 | 未規定 | 視為放棄查驗（AI 不會發生） |
| 白癡翻牌逾時 | 「可以翻牌」 | 預設翻牌免死（對玩家有利的預設） |
| 警徽移交逾時 | 未規定 | 視為撕毀警徽 |
| 飢荒逾時系統代投 | 「隨機投給一名合法目標」 | 隨機時排除自己（仍可主動投自己） |
| 目的地逾時未確認 | 「隨機代選不消耗夜行令」 | 沿用白天暫選；無暫選則於三張牌中隨機 |

## 夜間與能力裁定

| 情境 | 規則文件 | 實作裁定 |
|---|---|---|
| 建設完成的公告時機 | 「工程立即完成並扣除材料」 | 材料當夜扣除；完成於次日黎明公告（烽火台除外，當夜立即結算勝利） |
| 柵欄完成當夜的保護 | 未規定 | 自「下一夜」起生效（當夜刀殺與建設同屬 15 秒行動，不回溯） |
| 大燈完成當夜的情報 | 「建成後永久生效」 | 當夜人數即納入次日報告（從寬） |
| 女巫瀕死名單內容 | 「觀察…瀕死者」 | 只顯示「解藥可救」的目標：批次一排除狼人自殺；依房主設定排除自己。按鈕狀態即情報原則 |
| 獵人帶走能否觸發暗戀代死 | 矩陣僅列藥物／保護 | 可以觸發（比照騎士決鬥 QA 的代死先例；尾盡仍為唯一例外） |
| 狼人自爆能否觸發暗戀代死 | 未規定 | 可以；代死後自爆者存活，但「公開狼人陣營」「中止會議」「跳過放逐」效果不撤銷 |
| 殉情時暗戀對象的死因 | 「兩人一同死亡」 | 對象以原事件死因死亡（狼刀殉情的獵人對象黎明仍可開槍） |
| 守衛被花蝴蝶封鎖後的改選範圍 | 「改為前往一個地點正常工作」 | 任一開放地點 |
| 連守限制的認定 | 「前一晚選過的任何地點」 | 以「實際執行的巡邏」計；被封鎖而未執行者不受限 |
| 「每晚死亡結算後」九尾狐得知尾數 | — | 夜間結算完通知一次；自身角色面板亦隨時顯示目前尾數 |
| 匿名外觀 | 「看不到自己的匿名外觀」 | 他人可辨識彼此的外觀（依房主設定整局固定或每晚重抽）；地點文字頻道以外觀名發言 |
| 夜間祕密階段的存在感 | — | 非參與者一律顯示「夜色深沉」；夜晚總時長仍隨技能觸發而變（未做時間填充，列為未來工作） |

## 資訊與觀戰裁定

| 情境 | 規則文件 | 實作裁定 |
|---|---|---|
| 死者觀戰能看到什麼 | 僅規定死亡警長不得用觀戰資訊移交警徽 | 死者可見全部身分與目的地（上帝視角）＋收到所有頻道；**持有待移交警徽者在決定前不給任何觀戰資訊與頻道** |
| 警長投票／建設表決的投票者公開 | 17.1 未列 | 只公開各候選人／提案得票數，不公開個別投票者 |
| 資源公開模式 3 的縱火顯示 | 「詳細模式可能讓破壞較易被推理」 | 各地點產量正常列出，縱火另列「不明損失 -N」 |

## 技術限制

- 語音以文字承載；WebRTC 變聲語音為未來工作（頻道模型已就緒）。
- AI 為啟發式（LM AI 屬內部附錄 §10 的獨立規格）。狼人 AI 不會自爆、不會假跳預言家（僅泛用指控），屬可加強項。
- 伺服器記憶體保存對局；重啟丟失進行中對局。
- 長按工作以伺服器時間計，容忍網路延遲（按住期間跨 tick 累計）。
